Skill: Implement Task
Quando utilizar

Use ao implementar uma tarefa já especificada.

Entrada necessária
caminho da tarefa;
plano aprovado;
arquivos permitidos;
comandos de validação.
Procedimento
Ler AGENTS.md.
Ler a tarefa.
Ler somente o contexto obrigatório.
Confirmar arquivos permitidos.
Confirmar arquivos proibidos.
Implementar o menor diff possível.
Criar ou atualizar testes.
Executar validações.
Revisar git diff.
Criar relatório.
Restrições
não aumentar escopo;
não instalar dependência sem justificativa;
não alterar migration aplicada;
não corrigir problemas não relacionados;
não reformatar arquivos inteiros sem necessidade;
não remover validação;
não ignorar teste quebrado;
não utilizar mock em produção.
Saída

Usar .ai/templates/REPORT_TEMPLATE.md.
