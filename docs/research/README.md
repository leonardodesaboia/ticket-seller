Pesquisas

Este diretório armazena estudos que ainda não são decisões oficiais.

Exemplos:

provedores de pagamento;
provedores de autenticação;
serviços de e-mail;
filas;
nuvens;
soluções antifraude;
check-in offline;
legislação;
custos.
Regra

Pesquisa não substitui ADR.

Uma pesquisa concluída deve gerar:

nenhuma ação;
tarefa;
experimento;
ou ADR.
